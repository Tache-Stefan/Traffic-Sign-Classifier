About This App

This web application allows users to classify traffic signs using deep learning models. It was designed to demonstrate how Convolutional Neural Networks (CNNs) and ResNet architectures can recognize traffic signs from images.

How It Works

Users can upload an image of a traffic sign, and the system will analyze it using one of two models:

  • CNN (Convolutional Neural Network): A deep learning model that detects features in images by applying multiple filters. It is well-suited for tasks like image classification due to its ability to recognize patterns such as edges, colors, and shapes.
  • ResNet (Residual Network): An advanced CNN model that includes skip connections, which help avoid problems like vanishing gradients in deep networks. ResNet achieves high accuracy and is widely used in computer vision applications.

Implementation

The models were trained on a traffic sign dataset and integrated into this web application using Flask (a Python web framework). Users can log in, upload images, and view performance statistics. The classification results are stored in a database so users can track their history and accuracy.
